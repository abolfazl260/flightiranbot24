# FlightIranBot24

FlightIranBot24 is a Telegram travel assistant with a Telegram Mini App and a separate Android application. It provides ticket-price information, visa guidance, alerts, and travel resources.

## Temporarily disabled Telegram features (2026-11-01)

To keep the public Telegram destination focused on fully functional services, **Airports**, **Traveler Rules**, and the **Telegram Mini App launch button** are intentionally hidden **until further notice**. They are disabled, **not deleted**, so their implementation can be completed and restored later.

| Feature | Telegram bot | Telegram Mini App |
| --- | --- | --- |
| Airports / فرودگاه‌ها | Main-menu button disabled/commented out; removed from welcome and `/help` | Home-page airport card and placeholder screen commented out |
| Traveler Rules / قوانین مسافر | Main-menu button disabled/commented out; no longer advertised in `/help` | No standalone traveler-rules destination to expose |
| Telegram Mini App launch / ورود به مینی‌اپ سفر | The `🚀 ورود به مینی‌اپ سفر` Web App button is commented out in the shared menu renderer (`/start`, help, language and back-to-menu) | The Mini App implementation, backend endpoints, assets and direct URL remain available; **this hides the bot button only** |

**Compatibility and access:** Previously sent `menu:airports`, `airports:page:*`, `airport:*`, and `menu:rules` inline buttons safely return users to the normal main menu. Existing `/start airports` deep links also show the main menu instead of the airport placeholder. This prevents old links from surfacing a disabled screen.

**Implementation retained:** Telegram airport services and traveler-rules modules remain in the repository; their public menu entries and Mini App airport markup are commented out. The Web App launch-button construction is also commented out in `src/flightiran/interfaces/telegram/keyboards.py`, but the URL validation and Mini App server are preserved. This is a **Telegram-specific change**; the Android application's airport directory is not modified.

**Important limitation:** This removes only the inline Mini App launch button generated by the bot. It does **not** disable the Mini App direct URL or any persistent Telegram menu button configured separately through `@BotFather` (`/setmenubutton`). Remove that BotFather button manually if configured. Previously sent Telegram messages containing an old Web App button may still be accessible.

**Re-enabling:** Complete and verify the features, restore the commented menu items and Mini App markup, update localized welcome/help descriptions, re-enable the corresponding routes and deep links, restore the Web App button code and its `WebAppInfo` import when reactivating the Mini App shortcut, update tests, and remove this temporary-disabled status from the README. Validate both mobile and desktop Telegram before publishing.
