# ویرایشگر محلی محتوای فرودگاه‌ها

این یک پنل فارسی برای آماده‌سازی **فایل‌های عمومی محتوای فرودگاه‌ها** است.
ورود کاربری، توکن GitHub، API مدیریتی و انتشار مستقیم ندارد.
فقط هنگام اجرای محلی از فایل‌های همین مخزن می‌خواند و JSON را روی دستگاه دانلود می‌کند.

## اجرا

در ریشه پروژه:

~~~bash
python -m http.server 8787 --bind 127.0.0.1
~~~

سپس این آدرس را باز کنید:

http://127.0.0.1:8787/tools/airport-content-editor/

**از مسیر ریشه مخزن** سرور را اجرا کنید. صفحه به مسیرهای
`/src/flightiran/modules/airport/data/airports.json` و
`/data/airports/airport-index.v1.json` نیاز دارد.

## گردش کار

1. فرودگاه را از فهرست اصلی انتخاب کنید؛ فرودگاهی که هنوز پرونده ندارد یک پرونده خالی جدید می‌گیرد.
2. یکی از بخش‌ها را ویرایش کنید یا از «افزودن +» بخش مستقل جدید بسازید.
3. متن، فهرست، لینک، تصویر، نقشه، ویدیو، تابلوی پرواز یا تجربه کاربران را به صورت بلوک اضافه کنید. عکس و ویدیو فعلاً **آدرس عمومی HTTPS** می‌گیرند؛ خود فایل رسانه آپلود نمی‌شود.
4. برای انتشار واقعی، منبع معتبر را ثبت کنید؛ «ثبت تاریخ بررسی امروز» را بزنید؛ وضعیت بخش را «منتشرشده» کنید. تجربه باید پیش از درج، ناشناس و تأییدشده باشد.
5. «دریافت فایل فرودگاه» خروجی `THR.v1.json` (یا کد فرودگاه دیگر) می‌دهد. آن را در `data/airports/details/` جایگزین کنید.
6. هنگام افزودن فرودگاه یا تغییر تیک فعال، «دریافت کاتالوگ» را نیز بزنید و فایل `airport-index.v1.json` را در `data/airports/` جایگزین کنید.
7. تغییرات را با یک Pull Request بررسی کنید. روی PR اعتبارسنجی Python و تست‌های Node اجرا می‌شود.

## ایمنی و انتشار

- پنل را روی اینترنت عمومی منتشر نکنید؛ این یک ابزار **local-only** بدون ورود کاربری است.
- به فایل JSON یا برنامه توکن، رمز، مشخصات خصوصی مسافران، متن تأییدنشده یا محتوای دارای حق نشر نامشخص اضافه نکنید.
- تا زمان MERGE شدن PR به `main`، خروجی‌های دانلودشده محتوای عمومی اپ را تغییر نمی‌دهند.
- بخش جدید با بلوک‌های پشتیبانی‌شده نیازی به تغییر قالب داده ندارد. نوع بلوک جدید به توسعه نسخه اپ نیاز دارد.
- داده پرواز به صورت زنده از این فایل‌های JSON تولید نمی‌شود؛ بلوک `flight_board` تنها قرارداد اشاره به منبع داخلی FIDS است.
- منطق انتشار سمت CI در `scripts/validate_airport_content.py` اعتبارسنجی نهایی را انجام می‌دهد. پیش‌نمایش داخل پنل مجوز انتشار نیست.
- این مرحله **پنل محلی تولید فایل** را اضافه می‌کند، نه مدیریت آنلاین دارای احراز هویت و انتشار مستقیم.
