# Real route-specific price charts (Telegram)

The /chart command and [direct Telegram link](https://t.me/Flightiranbot?start=chart)
open a two-step origin/destination selector in the private Telegram bot.

## Data and methodology

- **Source:** existing SQLite `mz724_price_snapshots` table, written by the
  scheduled MZ724 capture process. This is **not an external chart service**.
- **Window:** 21 UTC calendar days including today, matching the default
  retention period of price history. A route is selectable only if its
  observed data is retained in this window.
- **Metric:** the **minimum observed price (tomans)** for the exact
  origin/destination on each UTC day. The daily minimum is drawn from
  actual observations, not generated by interpolation or prediction.
- Missing dates are absent, with **no line** joining nonconsecutive days.
  No result for a route shows a plain informative message, never a synthetic
  chart. One observed day displays one dot and explicitly says a trend is
  not yet available.
- **Additional transparency:** shows the UTC observation period, number
  of days with data, total observations, historical min/max and actual
  last-observation timestamp. Does **not** claim live prices or bookability.
- Queries are scoped by both source and destination using SQLAlchemy
  parameters. The inline keyboard stores user-scoped *indices* for choices,
  not untrusted raw SQL or injected route names.
- Telegram renders a self-contained static **SVG inside an HTML widget**.
  No third-party JS, network calls, new service, migration or secret.
- Sending is limited to **private Telegram chats**. Bale transport is
  unchanged and never receives this widget.

## User experience

1. Open `https://t.me/Flightiranbot?start=chart` or send `/chart`.
2. Select a **departure city** from routes with stored history.
3. Select an **arrival city** that has historical observations for that origin.
4. The bot sends a price chart for that specific route.
5. Tap **انتخاب مسیر دیگر** to repeat the selection.

The existing `/fares` generic price widget, `/start fares` link,
Mini App, and Android functionality remain unchanged.

## Deployment

After CI checks succeed and the feature is merged, update the Telegram
bot on the existing server:

```sh
cd /opt/Flightiran/flightiranbot24
git pull --ff-only origin main
docker compose up -d --build bot
docker compose logs --tail=100 bot
```

If local files conflict with `git pull`, stop and resolve the conflict
without deleting `.env`, `cloudflare/wrangler.toml` or any SQLite volume.

If the chart says there are no observations, inspect the hourly capture job,
source availability, and configured retention. Do not insert fabricated
history to make the graph look full.

## Tests

```sh
ruff check src tests migrations
pytest tests/test_telegram_route_chart.py
```

Verify in Telegram (a compatible HTML Widgets client): direct link,
origin/destination selection, correct values and missing-day gaps,
and the one-day/empty-history state. GitHub CI covers data queries and UI
payload generation; live Telegram rendering still needs a client check.
